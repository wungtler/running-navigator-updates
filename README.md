# 러닝 내비게이션 개발 APK

안드로이드 러닝 코스 추천과 음성 안내 앱의 공개 배포 저장소입니다. 소스 저장소는 비공개로 유지합니다.

- Android 8.0 이상. 개발용 버전이며 실기기 야외 검증을 진행 중입니다.
- Releases에서 APK를 받아 기존 앱 위에 설치합니다. 기존 앱을 삭제할 필요가 없습니다.
- 0.2.0-dev부터 앱 내 업데이트를 사용할 수 있습니다. 현재 버전에서는 설정 → 앱 업데이트 → 업데이트 확인으로 진행합니다. 최초 0.2.0-dev는 직접 설치해주세요.
- 앱은 파일 크기·SHA-256·패키지·버전·기존 서명을 검증한 뒤 안드로이드 설치 화면으로 연결합니다. 설치 허용과 최종 확인은 사용자가 진행합니다.
- 신호등 적게는 등록된 OSM 신호등 주변 통과 추정입니다. 실제 대기 횟수나 모든 경로 중 최소를 보장하지 않습니다.
- 0.3.0-dev: 코스 입력/선택 화면 분리, 공용 지도와 고도·경사 그래프, 신호등 별도 회피 경로 탐색, 기록 개별 삭제, 앱 안내·변경 내역.
- 신호등 회피 후보는 등록된 신호등 지점을 제외해 추가 탐색합니다. 지역·데이터·서버 상태에 따라 별도 후보가 없을 수 있으며 네 가지 추천 종류에 코스를 연결하며 같은 경로가 선정되면 이를 표시합니다.
- 현위치와 러닝 시작은 갤럭시 Z 폴드 7에서 사용자 정상 동작 제보가 있습니다. 장시간 야외 러닝과 화면 꺼짐·음성 안내는 추가 검증 대상입니다.
- 위치 기록과 서명 키, 인증정보는 이 저장소에 올리지 않습니다.

`dev.json`은 앱에서 사용하는 개발 채널 업데이트 정보입니다. APK는 동일한 개발 서명을 유지합니다.

0.4.0-dev는 기록 상세 지도·1km 구간/잔여 구간·일요일 시작 달력·주간/월간 통계·메모·비슷한 거리 비교·계획 코스 재사용·파일 백업/복원을 제공합니다. 기존 기록은 보존하며 최근 20회 제한을 제거했습니다. 이전 기록에는 구간별 시간 자료가 없으므로 구간 페이스를 생성하지 않습니다. 삼성 헬스·스마트워치 연결은 후속 개발 예정입니다. 설정에서 업데이트할 수 있습니다.

0.5.0-dev는 러닝 안내 지도에 현위치·이동 방향·남은 코스 화살표·기록 경로를 표시합니다. 현위치 따라가기와 전체 코스, 자동 재탐색 지도 반영을 지원합니다. 차량 속도 거리 제외는 유지하고 신뢰 가능한 지도 위치 갱신을 분리했습니다. GPS 상태와 거리 제외 이유를 표시합니다. 기존 기록/메모는 유지되며 설정에서 업데이트할 수 있습니다.

0.5.1-dev는 목표 거리 최대값을 42.195km(마라톤 풀코스)로 늘립니다. 실제 생성 코스는 도로 구조에 따라 이보다 길거나 짧을 수 있으며 실제 거리와 오차를 표시합니다. 풀코스 빠른 선택 및 장거리 경로 탐색 범위/기록 코스 재사용도 보완했습니다.

0.5.2-dev는 하단 메뉴의 안전 여백 중복과 러닝 종료 버튼 가림을 보완합니다. 실제 메뉴 높이에 맞춰 화면 끝 여백을 확보하며 화면 크기/글자 확대/키보드 변화에도 갱신합니다. 기존 기록과 메모는 유지합니다.

0.5.3-dev는 하단 메뉴 보완을 포함하며 화면 종료 직후 늦은 초기화/기록 요청으로 앱이 종료되는 경합을 보호합니다. 이미 접수된 기록/메모 저장은 완료하도록 유지합니다.

0.5.4-dev는 빠른 거리 선택을 5km · 10km · 15km · 하프 · 풀로 정리합니다. 기본 5km와 직접 3km 입력을 유지하며 하프는 21.0975km, 풀은 42.195km입니다.

0.5.5-dev는 출발지·도착지의 주소/장소명 검색을 추가하고 도착지 기본값을 출발지와 동일로 바꿉니다. 출발지 변경 시 기본 도착지도 따라가며 따로 지정한 도착지는 유지합니다. 도착지 선택창에서 출발지와 동일로 되돌릴 수 있습니다. 주소 검색은 기기의 검색 서비스를 이용하며 결과를 선택하고 지도에서 확인해주세요.

0.5.6-dev는 설정 항목을 여섯 버튼으로 정리하고 안내·변경 내역 등을 개별 팝업에서 표시합니다. 긴 내용은 팝업 안에서 스크롤하며 닫기/뒤로가기로 설정 목록에 돌아갑니다. 설정 → 앱 업데이트 → 업데이트 확인으로 새 버전을 받을 수 있습니다.

0.5.7-dev는 같은 길 반복·회전·유턴을 평가하고 공원·하천 주변 등록 보행로 경유점을 추가 탐색해 기존 코스 추천을 보완합니다. 반복이 심한 후보만 있으면 거리 범위를 최대 ±10%까지 넓혀 비교하고 오차를 표시합니다. 보행로 조회 실패 시 기본 탐색을 계속하며 특정 지역의 최적 코스를 보장하지 않습니다. 기존 기록·메모와 같은 개발 서명을 유지합니다.

0.5.7-dev/code19 검증: 단위 58개·관련 가상기기 통합 실행 19개 통과. 이전 code18 업데이트·동일 서명과 설치 후 기록/메모 보존을 확인했습니다. 적합한 코스가 하나면 목록을 억지로 채우지 않습니다.

0.5.8-dev는 등록 보행로의 연결을 따라 순환·왕복 후보를 만들고 실제 산책로 겹침 비율을 비교합니다. 전체 왕복과 반환 구간을 더한 순환을 구분하고 반환점 안내 및 돌아오는 구간의 GPS 진행을 보완했습니다. 공개 시험에서 서울숲 3km는 두 후보, 공지천 주변 42.195km 목표는 세 후보가 나왔습니다. 그중 의암호 순환·반환은 41.007km이며 공식 춘천마라톤 동선과 일치하지 않습니다. 모든 지역에서 후보 수나 산책로 비율을 보장하지 않습니다.

장거리 지도 조회는 서버의 대기 시간·가용 슬롯을 확인합니다. 최종 연속 검색 시험에서 장거리 준비는 약 116초였으며 서버 상황에 따라 더 오래 걸리거나 실패할 수 있습니다. 기존 기록·메모와 개발 서명을 유지합니다.

0.5.8-dev/code20 검증: 단위 78개·최종 관련 가상기기 통합 실행 23개 통과. 실제 API의 연속 코스 검색, 반환 GPS 진행, 지도·화면/기록 호환, 이전 code19의 업데이트 다운로드 및 실제 설치 후 기록·메모 보존을 확인했습니다. 개발 중 서버 실패를 보완한 결과이며 공개 서버 가용성과 실제 야외 코스 품질은 별도 확인이 필요합니다.

0.5.9-dev는 산책로와 흙길·등산로를 함께 우대하던 추천 오류를 보완합니다. 주변 도로 연결도 탐색하고 최종 코스의 등록 회피 구간을 확인합니다. 다져진 자갈길·포장 공원 길과 포장 오르막 선호는 유지합니다. 태그 누락·지도 서버 실패로 현장 산길을 완전히 배제할 수는 없습니다. 오산 5km 조회에서 4.968/4.992/5.004km 세 보행로 왕복 후보와 등록 회피 구간 겹침 0%를 확인했습니다. 개인 출발점과 경로는 공개하지 않습니다. CI 단위 92개·Lint·빌드 및 관련 네이티브 실행 20개를 통과했습니다.

0.5.9-dev/code21 배포 검증: 단위 92개·최종 관련 기기 실행 24회 통과. 이전 code20의 업데이트 다운로드·동일 서명과 실제 설치 후 기록/메모 보존을 확인했습니다. 설정 → 앱 업데이트 → 업데이트 확인으로 받을 수 있습니다.

0.6.0-dev/code22는 선택 경유지를 최대 3개 지원합니다. 지도·주소·현위치로 지정하고 표시된 순서를 바꾸거나 개별 삭제할 수 있습니다. 출발→모든 경유지→도착의 실제 최단 보행거리로 목표 최소값을 설정하며, 더 짧은 빠른 선택을 막고 현재 입력을 최소값으로 올려 안내합니다. 필요한 거리가 입력 상한 42.195km를 넘으면 위치 변경을 안내합니다.

미방문 경유지를 자동 재탐색에서도 유지하고 이미 통과한 곳은 제외합니다. 지도 번호·음성 통과 안내와 기록/백업/코스 재사용에 경유지 정보를 보존합니다. 등록 순환 후보와 거리 보정·주변 도로 조회도 보완했습니다. 코스 수·순환형·정확한 목표거리 일치는 지역과 지도 데이터에 따라 달라집니다.

최종 APK의 단위 111개·관련 기기 33회 실행 통과. 공개 피드/APK 일치와 이전 code21의 다운로드·동일 서명·설치 후 기록/메모 보존을 확인했습니다. 기존 개발 키·기록·메모를 유지하며 설정 → 앱 업데이트 → 업데이트 확인으로 설치할 수 있습니다.

0.6.1-dev는 편한 길·균형잡힌 길·경사로가 포함된 길·신호등이 적은 길을 각각 실제 코스 하나로 연결합니다. 추가 후보 목록 없이 버튼을 누르면 지도·거리·경사도가 함께 바뀝니다. 신호등 회피 후보는 일반 세 코스에 섞지 않으며 과도한 회전은 제외하고 적합한 후보의 신호등 추정 통과 횟수를 비교합니다. 근접한 순환 코스도 왕복 후보와 비교합니다. 같은 경로·자료 없음은 명시하며 신호등 조회의 서버 처리 슬롯도 확인하고 제한 대기를 최대 30초 적용합니다. 기존 경유지와 기록·메모·개발 서명을 유지합니다. 0.6.1-dev/code23은 게시되었지만 마지막 장거리 회귀가 실패하여 0.6.2-dev에서 보완합니다.


0.6.2-dev/code24는 네 가지 실제 코스 선택을 유지하고 일부 반환을 포함한 순환 후보의 비교 기준을 보완합니다. 단위 122개·Lint·APK 빌드 및 최종 관련 가상기기 33회 실행을 통과했습니다. 같은 개발 서명을 유지합니다. 공개 피드/APK 일치·앱 내 업데이트와 이전 code23 설치 후 기록·메모 보존까지 확인했습니다. 최종 관련 기기37회 실행 통과. 설정 → 앱 업데이트 → 업데이트 확인으로 설치할 수 있습니다.
